## V5-F.1 Purpose

This section is normative.

This is a narrow provenance amendment. It completes the machine-readable provenance of
Volume 5, Package 3 after the package was merged to the mainline. It records the source
snapshot, authoring, closure and freeze, and original package merge commits so that the
Package 3 lineage is temporally precise. It preserves Gate V5-G3 and does not reopen any
substantive Package 3 content.

## V5-F.2 Scope of amendment

This section is normative.

This amendment adds a single new provenance artifact (V5-F) and one approval record
(APP-V5-044) recording the Package 3 provenance. It does not modify any frozen Package 3
chapter (V5-21 through V5-31 or V5-E), does not alter any data definition, and does not
change the Gate V5-G3 disposition. The Package 3 freeze (PACKAGE-5-3, APP-V5-043) remains
