## V5-B.1 Purpose

This section is normative.

This is a narrow provenance amendment. It completes the machine-readable provenance
of Volume 5, Package 1 after the package was merged to the mainline. It records the
authoring, closure and freeze, and original package merge commits so that the
Package 1 lineage is temporally precise. It preserves Gate V5-G1 and does not reopen
any substantive Package 1 content.
