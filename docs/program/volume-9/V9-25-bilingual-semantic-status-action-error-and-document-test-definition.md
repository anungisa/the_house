## Purpose

This chapter defines the bilingual assurance obligations for governed concepts,
statuses, actions, errors, decisions, notifications, and documents in both official
languages. It defines what must be tested, not how any test is written or run, and
authorizes no execution, environment, or tool.

## String presence is not semantic equivalence

The presence of a translated string is held strictly distinct from accurate
translation and governed semantic equivalence. A present translated string can still
diverge in governed meaning. Every bilingual obligation is judged against the
governed semantic-equivalence oracle, and a translated string that diverges in
governed meaning is detected and rejected. Machine translation and literal string
matching cannot satisfy a semantic-equivalence obligation.

## Governed bilingual surface

Each canonical concept carries an English and a French semantic requirement. The
governed surface spans every status, every action, every error and denial message,
every notification, the financial concepts and their distinctions, every governed
decision, and every governed document. A status conveys the same governed meaning in
both languages; an error and its recovery guidance convey the same governed meaning
in both languages; and a document conveys the same governed meaning and legal effect
in both languages.

## Historical terminology

Historical and superseded terminology is preserved so that a record rendered in
either language remains faithful to the terminology in force when it was created.

## Boundary

No bilingual obligation in this chapter asserts a translation or conformance result.
Each is a documentary obligation only, awaiting a forward execution gate.
