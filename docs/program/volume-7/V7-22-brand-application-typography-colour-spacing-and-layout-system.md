## V7-22.1 Purpose

This section is normative.

This chapter defines the documentary visual language for the club-affiliation experience: brand application, typography, colour, spacing, and layout. It records design specifications in register REG-702 as documentary specifications and never as production tokens, stylesheets, or framework configuration.

## V7-22.2 Brand application

This section is normative.

Brand application is restrained and institutional. It signals a governed national-sport-organization service rather than a promotional product. Brand presence establishes trust and origin without competing with task content, status meaning, or evidence provenance. Brand application never implies that a screen confers authority, decision, or activation that the governed system has not recorded.

## V7-22.3 Typography

This section is normative.

Typography is specified by role and intent: a hierarchy for page titles, section headings, task labels, body content, supporting guidance, and consequential notices. Type roles preserve reading order and institutional emphasis, keep bilingual expansion legible, and never rely on colour alone to convey meaning. Typographic scale is described as relative role and hierarchy rather than as fixed production measurements or token values.

## V7-22.4 Colour

This section is normative.

Colour is specified by semantic role: neutral surfaces and text, informational emphasis, and the meaning families for received, in-review, returned, decided, active, and blocked conditions. Colour never carries meaning on its own; every status colour is paired with text and structure so that meaning survives for colour-blind users, in monochrome, and under low-bandwidth rendering. Colour roles are described by intent and are not expressed as production palettes or code.

## V7-22.5 Spacing and layout

This section is normative.

Spacing and layout are specified as a documentary rhythm and structure that keep governed content legible, group related task and evidence information, and preserve a stable reading order across surfaces. Layout supports responsive and low-bandwidth conditions and never hides institutional obligations, status meaning, or recovery paths behind density or motion. Measurements are described as relative rhythm and role, not as production values, tokens, or stylesheet rules.

## V7-22.6 Explicit non-authorizations

This section is normative.

This chapter authorizes no implementation. It creates no production content, final visual design, design tokens, stylesheet, framework configuration, coded interface, or design-system implementation, and no procurement, sequencing, staffing, cost, pilot, rollout, or master development plan. It defines a documentary visual language only, pending Gate V7-G3.
