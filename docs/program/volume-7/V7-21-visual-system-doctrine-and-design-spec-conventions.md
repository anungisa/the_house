## V7-21.1 Purpose

This section is normative.

This chapter opens Volume 7 Package 3, the visual, component, content, and reference-prototype definition for the club-affiliation experience. It establishes the doctrine and the specification conventions that govern every subsequent Package 3 chapter. Package 3 defines documentary design intent only. It inherits the frozen Package 1 experience foundation and the frozen Package 2 interaction model without modifying either.

## V7-21.2 Design definition is documentary and non-final

This section is normative.

Package 3 produces reference design candidates. It does not produce production user interface, production content, validated translations, design-system implementation, executable workflow, or any coded interface. A Package 3 artifact is never stakeholder-approved, never usability-validated, never production-final, and never implemented. Every controlled record carries a not-implemented-or-not-proven posture, and reference prototypes are recorded as reference candidates that are not approved.

## V7-21.3 Governed semantics precede visual form

This section is normative.

Every visual element, component, and content term derives from a governed semantic source established in Package 1 or Package 2. Visual form expresses governed meaning; it never invents authority, decision, activation, or standing. Where a visual state exists, its governed semantic source is named so that appearance can never drift away from institutional meaning.

## V7-21.4 Specification conventions

This section is normative.

Design specifications are expressed as prose and structured register records, not as code. Visual attributes such as typography, colour, spacing, and layout are described by role and intent rather than as production tokens, stylesheets, or framework configuration. Components are specified by anatomy, variants, states, permitted and prohibited uses, accessibility, bilingual expansion, privacy posture, and traceability. Reference prototypes are specified as documentary walkthroughs of governed flows.

## V7-21.5 Inheritance and additive discipline

This section is normative.

Package 3 inherits the corrected Volume 6 release baseline and the frozen Package 1 and Package 2 corpora. Prior artifacts are superseded only additively and never overwritten. Package 3 introduces new registers records under new identifier families and does not alter frozen Package 1 or Package 2 records. Volume 7 is not tagged.

## V7-21.6 Explicit non-authorizations

This section is normative.

This chapter authorizes no implementation. It creates no production user interface, production content, validated translation, final visual design, design-system implementation, design tokens, stylesheet, framework configuration, coded interface, executable workflow, or interface or integration contract, and no procurement, sequencing, staffing, cost, pilot, rollout, or master development plan. It defines documentary design doctrine and specification conventions only, pending Gate V7-G3.
