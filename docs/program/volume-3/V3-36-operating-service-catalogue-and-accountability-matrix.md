## V3-36.1 Purpose

This section is normative.

This chapter defines the controlled operating service catalogue and functional accountability
matrix for operating the affiliation service (CAP-V3-036, OUT-V3-036, FR-V3-036). It uses
functional RACI-style accountability and assigns no named employees or approved organizational
positions.

## V3-36.2 Service families

This section is normative.

The catalogue defines the following service families:

- seasonal readiness;
- club recognition;
- pathway determination;
- affiliation-case administration;
- evidence administration;
- jurisdictional review;
- national escalation;
- policy exception handling;
- financial reconciliation;
- activation operations;
- support and recovery;
- communications operations;
- privacy and restricted-evidence handling;
- bilingual and accessibility assurance;
- management reporting;
- operational assurance;
- continuity;
- seasonal closure and review.

## V3-36.3 Service record

This section is normative.

For each service the catalogue records:

```
Service identifier
Service purpose
Primary beneficiary
Accountable function
Responsible performer
Consulted functions
Informed parties
Decision rights
Entry condition
Exit condition
Evidence
Control
Escalation
Continuity posture
Validation status
```

## V3-36.4 Functional accountability constraint

This section is normative.

Accountability is expressed with functional RACI (accountable, responsible, consulted, informed)
against operating functions, never against named individuals or approved organizational positions
(BR-V3-038, RULE-V3-030, CTRL-V3-043). A service is complete only when its accountable function,
responsible performer, decision rights, entry and exit conditions, evidence, and control are all
recorded.

## V3-36.5 Validation status

This section is normative.

The catalogue is author-asserted. Operating validation involves Curling Canada National
Operations (STK-V3-001), the PTSO and member associations (STK-V3-002), and clubs (STK-V3-003).
Pending validation blocks only the affected service record.
