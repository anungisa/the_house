## V3-24.1 Purpose

This section is normative.

This chapter defines the controlled improvement cycle for the affiliation service
(CAP-V3-024, OUT-V3-024, FR-V3-024). An improvement proposal, however operationally
desirable, does not authorize implementation or procurement (BR-V3-023, RULE-V3-019,
CTRL-V3-028). It authorizes no implementation.

## V3-24.2 Improvement cycle

This section is normative.

The governed improvement cycle proceeds through the following stages:

```
Operational evidence collection
→ seasonal review
→ control-effectiveness review
→ stakeholder feedback
→ problem-pattern analysis
→ improvement proposal
→ authority classification
→ validation
→ approval
→ future-volume or operating-change routing
```

## V3-24.3 Improvement inputs

This section is normative.

The improvement cycle draws on the following operational inputs:

- Lessons learned.
- Recurring exceptions.
- Pathway-distribution changes.
- Evidence burdens.
- Reviewer consistency.
- Financial mismatches.
- Support demand.
- Accessibility and bilingual defects.
- Privacy concerns.
- External-dependency failures.
- Control deficiencies.
- Unvalidated assumptions.
- Pilot and production evidence.

## V3-24.4 Authority classification and routing

This section is normative.

Each improvement proposal is classified by authority and routed to a future volume or to
the operating-change process (V3-20); it does not become implementation authorization by
virtue of operational desirability (RULE-V3-019). Improvement proposals that would require
staffing, cost, procurement, or implementation escalate to the material organizational
commitment context (V3-17), which is not exercised in Volume 3.

## V3-24.5 Management assurance

This section is normative.

Seasonal review and control-effectiveness review feed the risk and assurance model (V3-19)
and produce retained, reconstructable assurance evidence (NFR-V3-007, CTRL-V3-029). The
unresolved validation backlog (V3-07) is reviewed each cycle.

## V3-24.6 Validation status

This section is normative.

The continuous-improvement definitions are author-asserted. Improvement governance
validation involves the risk and assurance function (STK-V3-018) and Curling Canada
National Operations (STK-V3-001); measure baselines require operating and pilot evidence.
Pending validation blocks only the affected improvement definition.
