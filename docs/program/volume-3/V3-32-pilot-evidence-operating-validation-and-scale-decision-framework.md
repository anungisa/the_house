## V3-32.1 Purpose

This section is normative.

This chapter defines the operating evidence required before broader organizational
commitment and the decision criteria that evidence supports (CAP-V3-032, OUT-V3-032,
FR-V3-032). It defines evidence and decision criteria only. It must not authorize a pilot,
launch, rollout, or implementation, and it authorizes no implementation.

## V3-32.2 Evidence families

This section is normative.

The required evidence families include:

- Actual club-case volumes.
- Pathway distribution.
- Review effort.
- Evidence burden.
- Return and resubmission frequency.
- Routing accuracy.
- Policy-exception demand.
- Financial-reconciliation effort.
- Activation recovery.
- Support demand.
- Bilingual equivalence.
- Accessibility task completion.
- Privacy exceptions.
- External-provider failures.
- Queue aging.
- Control effectiveness.
- Audit reconstruction.

## V3-32.3 Scale-decision classifications

This section is normative.

Operating evidence is assessed against a scale-decision classification (BR-V3-033,
RULE-V3-026, CTRL-V3-039):

```
READY_FOR_VALIDATION
VALIDATION_IN_PROGRESS
EVIDENCE_INSUFFICIENT
OPERATING_MODEL_ADJUSTMENT_REQUIRED
POLICY_DECISION_REQUIRED
FINANCIAL_DECISION_REQUIRED
MATERIAL_COMMITMENT_REQUIRED
```

A scale decision requires sufficient operating evidence for its decision class; insufficient
evidence blocks the decision rather than authorizing execution.

## V3-32.4 Constraint

This section is normative.

This chapter defines evidence and decision criteria. It does not authorize a pilot, launch,
rollout, or implementation (BR-V3-033, NFR-V3-012). Readiness and pilot evidence is recorded
so that a scale decision can be reconstructed from the evidence that supported it.

## V3-32.5 Validation status

This section is normative.

The evidence and scale-decision definitions are author-asserted. Operating-validation
involvement includes the affiliation service owner (STK-V3-017), the risk and assurance
function (STK-V3-018), and Curling Canada National Operations (STK-V3-001); most evidence
families require production and pilot evidence baselines. Pending validation blocks only the
affected evidence or decision definition.
