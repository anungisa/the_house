# Volume 3 - Business Operating Model

Volume 3 defines the business operating model required to deliver the governed
affiliation service of The House v2 consistently, accountably, and sustainably. It
proceeds from the frozen Volume 0 foundation, the corrected Volume 1 v1.0.1 baseline,
and the corrected Volume 2 v1.0.1 product-and-service definition, and authorizes **no**
staffing, cost, procurement, technical architecture, delivery sequencing, master
development plan, or implementation.

## Governance controls

Run `npm run governance:check:v3` to validate structural/schema conformance and
cross-reference/traceability integrity, `npm run governance:trace:v3` for the
traceability projection, and `npm run governance:report:v3` for the control report. The
Markdown chapters, YAML registers, JSON schemas, and control scripts are the
authoritative record; generated reports are non-authoritative projections. Volume 0,
Volume 1, and Volume 2 remain frozen and are not modified by Volume 3 work.
