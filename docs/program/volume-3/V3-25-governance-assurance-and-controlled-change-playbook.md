## V3-25.1 Purpose

This section is normative.

This chapter consolidates the Package 3 operating-governance model into a single playbook
and explicitly records the matters outside Package 3 (CAP-V3-025, OUT-V3-025, FR-V3-025,
BR-V3-024). It authorizes no implementation.

## V3-25.2 Playbook structure

This section is normative.

The Package 3 governance playbook consolidates:

- Governance forums (V3-17).
- Decision-rights model (V3-17).
- Reporting (V3-18).
- Performance review (V3-18).
- Risk register (V3-19).
- Control and assurance model (V3-19).
- Operating-change process (V3-20).
- External dependency oversight (V3-21).
- Information stewardship (V3-22).
- Incident and continuity governance (V3-23).
- Continuous improvement (V3-24).
- Unresolved validation backlog (V3-07, V3-24).

## V3-25.3 Explicit exclusions

This section is normative.

The playbook explicitly excludes, and Package 3 does not authorize, the following
(BR-V3-025, CTRL-V3-031):

- Permanent organizational design.
- Approved committees or meeting calendars.
- Permanent staffing.
- Salary or cost model.
- Vendor selection.
- Procurement.
- Technical architecture.
- Security implementation.
- Monitoring tooling.
- Software implementation.
- Delivery sequencing.
- Master development plan.

## V3-25.4 Relationship to the operating model

This section is normative.

The playbook governs the seasonal operating process (Package 2) and the institutional
operating model (Package 1) without altering their frozen content. Governance forums,
controls, and change classes reference the operating model rather than restating it.

## V3-25.5 Validation status

This section is normative.

The playbook is author-asserted and inherits the validation status of the chapters it
consolidates. Material organizational commitment, permanent organizational form, and cost
require executive acceptance at a later gate (Nolan). Pending validation blocks only the
affected governance element.
