## V3-39.1 Purpose

This section is normative.

This chapter consolidates the operating measures and assurance evidence needed to manage the
affiliation service (CAP-V3-039, OUT-V3-039, FR-V3-039). It invents no numerical target or
escalation threshold and authorizes no implementation.

## V3-39.2 Measure families

This section is normative.

The baseline consolidates the following measure families:

- readiness completion;
- cases opened;
- pathway distribution;
- queue aging;
- routing accuracy;
- evidence burden;
- returns and resubmissions;
- reviewer consistency;
- decision-authority compliance;
- financial mismatches;
- activation success and recovery;
- support demand;
- privacy events;
- bilingual defects;
- accessibility issues;
- external dependency failures;
- continuity performance;
- control effectiveness;
- audit reconstruction;
- seasonal closure.

## V3-39.3 Measure record

This section is normative.

For each measure the baseline records:

```
Measure identifier
Operating outcome

Calculation concept
Evidence source
Accountable owner
Decision supported
Baseline status
Target status
Assurance relationship
Validation authority
Future blocking gate
```

## V3-39.4 No-fabricated-target constraint

This section is normative.

Every measure records an accountable owner and a baseline status; no numerical target or
escalation threshold is invented (BR-V3-042, RULE-V3-033, CTRL-V3-047). Targets remain
baseline-pending until validated by the accountable owner and validation authority.

## V3-39.5 Validation status

This section is normative.

The measure baseline is author-asserted. Assurance validation involves Curling Canada National
Operations (STK-V3-001) and the risk and assurance function (STK-V3-018). Pending validation
blocks only the affected measure.
