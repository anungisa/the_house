# V0-07 - Governance and Decision Rights

Document ID: V0-07  
Status: DRAFT  
Version: 0.1.0

Defines program authorities, decision classes, and escalation rules.

Decision classes and approvers are controlled in REG-002 and REG-006.

Note (forward dependency): principles in V0-05 and the initial decisions in Annex B
already reference decision classes D0 through D9 provisionally. The authoritative
definition of those classes and their approvers is drafted here and MUST be
ratified in Package 2. Until ratification, those references are provisional and
non-authoritative.

Ratification target: Package 2.
