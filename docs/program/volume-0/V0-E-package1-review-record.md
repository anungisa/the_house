   classification and per-problem structure.
6. Outcomes not decision-grade - V0-03 adds baseline/target method, measures,
   owner, evidence source, and anti-gaming notes.

   (OUT-010, PR-020).
8. First production flow under-defined - V0-04 4.5 defines the complete affiliation
   outcome including exactly-once activation.
9. Source hierarchy conflict handling - to be fully hardened in V0-10/Package 3;
   authority correction applied now.
10. Methodology crosswalk - added as Annex A.
11. Registers machine-readable but not machine-governed - stated honestly; schema
    and CI checks deferred to Package 3.
12. Gate G0 - set to HOLD - constitutional drafting underway.
