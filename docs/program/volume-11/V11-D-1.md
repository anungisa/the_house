## Purpose

This chapter records the authoritative provenance-role classification for Volume 11
Package 2. It binds each Package 2 provenance commit to its distinct role, so that
authoring, closure and freeze, pre-merge binding, the original merge, and the
post-merge provenance amendment are never conflated. It is additive metadata only. It
reopens no substantive content, no gate disposition, and no freeze, and it authorizes
no operation.

## Why role classification is recorded here

The role classification binds the original-merge commit and the provenance-amendment
commits, none of which exist until after Package 2 and its first post-merge amendment
(V11-D) are merged. Recording the classification honestly therefore requires this
second, final post-merge amendment. Until now the classification was pending; with
this chapter it becomes applicable and enforceable.

## The classified roles

Each Package 2 provenance commit is classified into exactly one role in REG-1105:

- Source baseline: the inherited mainline baseline the branch started from.
- Substantive authoring: the commit that authored the Package 2 content.
- Closure and freeze: the commit that authored closure, gate disposition, and freeze.
- Pre-merge provenance binding: the commit that bound the concrete closure and freeze
  commit before the merge.
- Original package merge: the commit that integrated Package 2 into the mainline.
- Provenance-amendment authoring and merge: the commits of the first post-merge
  amendment (V11-D) that recorded the binding and original-merge commits.
- Inherited release tag: the inherited baseline tag.

## Integrity properties preserved

- The source baseline is distinct from substantive authoring.
- Substantive authoring is distinct from closure and freeze.
- The pre-merge provenance-binding commit is distinct from the amendment commits.
- No provenance value remains a placeholder.
- No record authorizes implementation or operations.

## Boundaries

- The substantive Package 1 and Package 2 content remains frozen and unchanged.
- Gate V11-G2 remains dispositioned as recorded at closure.
- Volume 11 is not tagged by this amendment.
- This amendment authorizes no implementation and no operations.
