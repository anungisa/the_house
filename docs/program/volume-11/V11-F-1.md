## Purpose

This chapter records the authoritative provenance-role classification for Volume 11
Package 3 and records the Volume 11 release tag. It binds each Package 3 provenance
commit to its distinct role, so that authoring, closure and dual freeze, pre-merge
binding, the original merge, and the post-merge provenance amendment are never
conflated. It is additive metadata only. It reopens no substantive content, no gate
disposition, and no freeze, and it authorizes no operation.

## Why role classification is recorded here

The role classification binds the original-merge commit and the provenance-amendment
commits, none of which exist until after Package 3 and its first post-merge amendment
(V11-F) are merged. Recording the classification honestly therefore requires this
second, final post-merge amendment. Until now the classification was pending; with this
chapter it becomes applicable and enforceable.

## The classified roles

Each Package 3 provenance commit is classified into exactly one role in REG-1105:

- Source baseline: the inherited mainline baseline the branch started from.
- Substantive authoring: the commit that authored the Package 3 content.
- Closure and dual freeze: the commit that authored closure, gate disposition, the
  Package 3 freeze, and the whole-volume freeze.
- Pre-merge provenance binding: the commit that bound the concrete closure and freeze
  commit before the merge.
- Original package merge: the commit that integrated Package 3 into the mainline.
- Provenance-amendment authoring and merge: the commits of the first post-merge
  amendment (V11-F) that recorded the binding and original-merge commits.
- Inherited release tag: the inherited Volume 10 baseline tag.
- Applied release tag: the Volume 11 release tag applied after this amendment merges.

## Volume 11 release tag

After this amendment merges, the Volume 11 corpus is tagged
`central-registration-volume-11-v1.0.0` on the merge commit of this amendment. The
release tag records a documentary release of the frozen Volume 11 corpus. It confers
no operational readiness and authorizes no operation, migration, recovery, adoption,
provider engagement, or launch.

## Integrity properties preserved

- The source baseline is distinct from substantive authoring.
- Substantive authoring is distinct from closure and dual freeze.
- The pre-merge provenance-binding commit is distinct from the amendment commits.
- No provenance value remains a placeholder.
- No record authorizes implementation or operations.

## Boundaries

- The substantive Package 1, Package 2, and Package 3 content remains frozen and
  unchanged.
- Gate V11-G3 remains dispositioned as recorded at closure.
- The release tag records a documentary release only.
- This amendment authorizes no implementation and no operations.
