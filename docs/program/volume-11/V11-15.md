## Purpose

This chapter defines documentary continuity, backup, restore, recovery, and
degraded-operation procedures for the affiliation vertical. It defines obligations
only and authorizes no backup, restore, recovery, or continuity execution.

## Procedures

Documentary procedures are defined for identity-provider unavailability, database
interruption, application outage, evidence-storage outage, payment or
accounting-provider outage, delayed event delivery, outbox backlog, stale
projections, partial service, inaccessible documents, batch partial failure,
support-channel disruption, manual fallback, backup verification, restoration,
service recovery, business reconciliation, and return to normal operation. Each
procedure in REG-1102 records its failure stimulus, affected service, authoritative
state at risk, preserved work, prohibited operations, degraded posture, fallback
dependency, backup dependency, restore dependency, recovery dependency,
reconciliation dependency, outstanding-obligation treatment, required evidence,
exercise environment, decision authority, and future gate.

## Controlling distinctions

> Backup generated is not backup verified is not backup restorable.
>
> Restore completed is not service recovered.
>
> Service recovered is not data reconciled is not outstanding obligations completed.
>
> Documented fallback is not proven fallback capability.

A generated backup is not a verified backup, and a verified backup is not a restorable
backup. A completed restore is not a recovered service; a recovered service is not
reconciled data; and reconciled data does not complete outstanding obligations. A
documented fallback is not a proven fallback capability.

## Boundary

This chapter defines documentary procedures. No backup, restore, recovery, or
continuity exercise is executed and no recovery capability is claimed.
