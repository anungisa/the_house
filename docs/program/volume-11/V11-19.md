## Purpose

This chapter defines documentary provider-operations, continuity, incident, return,
deletion, substitution, and exit runbooks for the affiliation vertical. It defines
obligations only and authorizes no provider engagement, integration, or exit.

## Runbooks

Documentary provider runbooks are defined for identity providers, payment and
accounting providers, evidence and document storage, communication providers, hosting
and platform providers, and subcontracted services. Each provider context in REG-1101
and each requirement in REG-1102 records its institutional owner, contract owner,
service dependency, data custody, authority retained, authentication dependency,
incident obligation, continuity obligation, subcontractor dependency, return
requirement, deletion evidence requirement, residual-copy posture, backup posture,
substitution dependency, exit procedure, provider-certification boundary,
end-to-end-assurance boundary, and future gate.

## Controlling distinctions

> Provider certification is not operational assurance.
>
> Provider availability is not end-to-end service availability.
>
> Provider custody is not Curling Canada authority.
>
> Contract termination is not data return or deletion completion.

A provider certification bounds the provider platform only and is not operational
assurance of the governed service. Provider availability is not end-to-end service
availability. Provider custody of data is not Curling Canada authority over it, and
contract termination does not by itself complete data return or deletion. These
distinctions are recorded as decisions ADR-V11-003 and ADR-V11-009.

## Boundary

This chapter defines documentary runbooks. No provider is engaged, integrated,
substituted, or exited, and no data is returned or deleted.
