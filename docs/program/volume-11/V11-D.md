Ratification: Ratified as an additive post-merge provenance amendment to Package 2.

## Purpose

This chapter is the post-merge provenance amendment for Volume 11 Package 2. It
records the two commits that could not exist until after Package 2 was merged: the
pre-merge provenance-binding commit and the original Package 2 merge commit. It is
additive metadata only. It reopens no substantive content, no gate disposition, and
no freeze. It authorizes no operation.

## Why a post-merge amendment is required

The Package 2 authoring, closure, gate disposition, and freeze were recorded before
the merge. Two provenance facts are only knowable after the merge: the identity of
the pre-merge provenance-binding commit, and the identity of the merge commit that
integrated Package 2 into the mainline. Recording them honestly requires an additive
amendment made after the merge. Before this amendment those values were recorded as
pending, so that no fabricated identity was ever asserted.

## What this amendment records

This amendment resolves the previously pending provenance-binding commit to the
concrete pre-merge provenance-binding commit and records the original Package 2 merge
commit in the Package 2 freeze record (REG-1105). No frozen artifact content is
altered; only provenance metadata is completed.

## Boundaries

- The substantive Package 2 content remains frozen and unchanged.
- Gate V11-G2 remains dispositioned as recorded at closure.
- The role classification of these commits is recorded separately by the follow-on
  amendment V11-D-1, which binds this amendment's own authoring and merge commits.
- This amendment authorizes no implementation and no operations.
