## Purpose

This chapter records the authoritative provenance-role classification for Volume 12
Package 3 and the doctrine under which the Volume 12 corpus release tag is applied. It
binds each Package 3 provenance commit to its distinct role, so that authoring, closure
and freeze, pre-merge binding, the original merge, and the post-merge provenance
amendment are never conflated. It is additive metadata only. It reopens no substantive
content, no gate disposition, and no freeze, and it authorizes no implementation, no
evidence acceptance, and no release.

## Why role classification is recorded here

The role classification binds the original-merge commit and the provenance-amendment
commits, none of which exist until after Package 3 and its first post-merge amendment
(V12-F) are merged. Recording the classification honestly therefore requires this
second, final post-merge amendment. Until now the provenance-integrity control reported
that this classification was pending; with this chapter it becomes applicable and
enforceable.

## The classified roles

Each Package 3 provenance commit is classified into exactly one role in REG-1205:

- Source baseline: the inherited Package 2 baseline the branch started from.
- Substantive authoring: the commit that authored the Package 3 content.
- Closure and freeze: the commit that authored closure, gate disposition, and the
  triple freeze.
- Pre-merge provenance binding: the commit that bound the concrete closure and freeze
  commit before the merge.
- Original package merge: the commit that integrated Package 3 into the mainline.
- Provenance-amendment authoring and merge: the commits of the first post-merge
  amendment (V12-F) that recorded the binding and original-merge commits.
- Inherited release tag: the inherited Volume 11 baseline tag.
- Applied release tag: the Volume 12 corpus release tag applied after this amendment.

## Integrity properties preserved

- The source baseline is distinct from substantive authoring.
- Substantive authoring is distinct from closure and freeze.
- The pre-merge provenance-binding commit is distinct from the amendment commits.
- No provenance value remains a placeholder.
- No record authorizes implementation, operations, evidence acceptance, or release.

## Volume 12 release-tag doctrine

Only after this provenance-role classification is merged is the release tag
`central-registration-volume-12-v1.0.0` applied. The release tag records a documentary
release of the Volume 12 corpus and, with the corpus freeze
`CENTRAL-REGISTRATION-DEFINITION-CORPUS`, of the whole central-registration definition
corpus. It is not a software release, not an evidence acceptance, not a gate passage
beyond the Volume 12 definition gates, and not a production authorization. The next
action after the tag is a separate implementation-authorization decision package, not an
implied Volume 13.

## Boundaries

- The substantive Package 3 content remains frozen and unchanged.
- Gate V12-G3 remains dispositioned as recorded at closure.
- The Package 3, whole-volume, and whole-corpus freezes remain as recorded at closure.
- This amendment authorizes no implementation, no operations, no evidence
  acceptance, and no release.
