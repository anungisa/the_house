## Purpose

This chapter defines the controlled final evidence dossier and the separate
decision and release artifacts that draw from it. It defines the dossier structure;
it assembles no dossier, takes no decision, and issues no release note.

## The controlled final dossier

The final dossier is recorded in register REG-1202 as a dossier, and must contain:

```
Release-candidate identity
Scope and excluded scope
Institutional outcomes
Requirement coverage
Implementation evidence
Test evidence
Security and privacy evidence
Accessibility evidence
Bilingual evidence
Financial and reconciliation evidence
Migration evidence
Operational evidence
Provider evidence
Training and adoption evidence
Defects and evidence gaps
Exceptions and waivers
Material commitments
Independent assurance
Acceptance decisions
Dissent and conditions
Rollback dependency
Release authorization
Post-deployment obligations
```

## Separate artifacts

The following artifacts are defined as separate dossiers or briefs, each recorded
in register REG-1202 with an authoritative source:

- technical evidence dossier;
- operational-readiness dossier;
- migration-acceptance dossier;
- independent-assurance summary;
- business-acceptance brief;
- executive decision brief;
- release authorization record;
- release notes;
- stabilization and post-release obligations.

## Projection boundary

Generated summaries of the dossier are projections of authoritative records and are
never themselves authoritative. A projection is never evidence, never an
acceptance, and never a release authorization.

## Boundary

This chapter records the final-dossier and decision-brief model. It assembles no
dossier, takes no executive decision, issues no release note, and authorizes no
release. Every record carries the fixed non-authorizing posture.
