## V6-07.1 Purpose and scope

This section is normative.

This chapter defines the accessibility and bilingual-equivalence baseline as
governed obligations. It claims no accessibility conformance and authorizes no
remediation or implementation.

## V6-07.2 Accessibility obligations

This section is normative.

User-facing governed service must be perceivable and operable by users with
disabilities (A11Y-V6-001) and compatible with common assistive technologies
(A11Y-V6-002). Each accessibility obligation names a user need, an affected
workflow, a required behaviour, and a verification method. Verification and
conformance evidence are recorded as pending independent validation.

## V6-07.3 Bilingual-equivalence obligations

This section is normative.

Governed service must be available with semantic equivalence in both official
languages (BIL-V6-001), and notices, decisions, and evidence-facing content must be
semantically equivalent across languages (BIL-V6-002). Bilingual equivalence means
functional and semantic equivalence — the same governed meaning — not mere
translation. Each bilingual obligation names an equivalent concept and a
verification method.

## V6-07.4 Rights linkage

This section is normative.

The accessibility and bilingual obligations satisfy the right to accessible and
bilingual service (RIGHT-V6-005). They are protection obligations on the same
footing as security and privacy obligations.

## V6-07.5 Validation dependency

This section is normative.

Accessibility conformance and bilingual equivalence must be independently
validated before reliance (ASSR-V6-003, TEST-V6-003). No conformance is claimed by
this chapter.

## V6-07.6 Explicit non-authorizations

This section is normative.

This chapter authorizes no accessibility remediation, interface implementation, or
conformance claim. It records accessibility and bilingual obligations and their
verification methods only.
