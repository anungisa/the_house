## V6-D.1 Purpose

This section is normative.

This is a narrow provenance amendment. It completes the machine-readable provenance
of Volume 6, Package 2 after the package was merged to the mainline. It records the
authoring, closure and freeze, and original package merge commits so that the
Package 2 lineage is temporally precise. It preserves Gate V6-G2 and the Package 2
freeze and does not reopen any substantive Package 2 content.

This section is normative.
